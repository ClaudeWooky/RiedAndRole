-----------------
Projet: Site d'association de Jeux de rôles
-----------------
Le site contient 2 parties:
- Front-end: pour la partie visible du public qui est elle meme divisée en 2 partie: pour publics et pour administrateurs
- Back-end: pour tout ce qui concerne la gestion des comptes
-------------------
Partie pour publics: plusieurs pages:
- Home: pour un résumé des informations récentes de l'association recupérées des autres pages
- Jeux de rôles: les JdR que les membres de l'association savent maitriser
- Evénements: présente des informations concernant les événements auquels participe l'association
- Agenda: pour montrer les dates importantes pour l'association (événements, liens avec Ludoried, ...)
- Blog: articles écrits par les membres de l'Equipe qu'ils jugent interessants. Plusieurs catégories: annonce, critique de jeu, conseil MJ, Bons plans, ...
- Bibliothéque: liste les livres de Jeux de rôles appartenant à l'association
- Wishlist: liste les livres de Jeux de rôles désirés par les membres de l'association
- L'Equipe: présentant les mebres de celle-ci mais aussi les MJ qui participent aux journées découvertes et événements de l'association
- Contacts: information concernant l'association: adresse, liens vers le discord, le mail, les cotisations, ... mais aussi un formulaire pour joindre l'association.

Partie pour Administrateurs: plusieurs pages:
- Evénements: formulaire pour créer un événement
- Agenda: formulaire pour créer une entrée dans l'Agenda
- Jeux de rôles: une description des jeux de rôle que l'association est capable de proposer. Soit parce qu'elle posséde les livres permettant d'y jouer, soit parce qu'un MJ gravitant autour de l'association les posséde et est capable de le masteriser.
- Wishlist: gerer la wishlist - rajouter des tags pour annoncer coté public l'etat des articles (Achat validé, ...)
- L'Equipe: formulaire pour créer une entrée dans l'Equipe ou un nouveau MJ
- Blog: Gestion d'article visibles coté publique. Possibilité d'envoyé les articles sur Discord
- Bibliothèque: ouvrage appartenant à l'association
- Parties: pour rentrer les parties/scenario joués dans le cadre de l'associatiopn pour des besoin de statistique et de rapport
- Comptabilité: gestion de l'argent: achat de nouveau materiel/livres, subventions, ...
- Statistiques: Calcul des statistiques pour une certaine période (JdR joués, les lieux utilisés, les événements, les MJ solicités, les achats de materiel, ...)
- Site: parametres du site, gestion de notifications, analytics, sauvegarde des données, gestion des comptes
